# 2 — Brand Brief (Identité visuelle)

## Univers
Magazine éducatif, **pratique et chaleureux**, ancré dans le **quotidien africain**. Sérieux mais
accessible. Le lecteur repart toujours avec quelque chose à appliquer.

## Couleurs (tokens CSS — `src/styles/global.css`)
| Rôle | Hex | Variable |
|---|---|---|
| Teal principal | `#0E8074` | `--teal` |
| Teal foncé | `#0B6E64` | `--teal-d` |
| Teal clair | `#12A594` | `--teal-l` |
| Jaune (nav, boutons) | `#FDD200` | `--yellow` |
| Jaune foncé | `#E9BE00` | `--yellow-d` |
| Navy (titres) | `#1B2545` | `--navy` |
| Crème (fonds doux) | `#FBF6F2` | `--cream` |
| Encre / texte | `#23302E` | `--ink` |
| Gris atténué | `#6B7A78` | `--muted` |

**Mode sombre** : fonds `#0E1716`/`#14201E`, texte clair, accents teal/jaune conservés.

## Typographie
- **Poppins** (Google Fonts), graisses 400 / 500 / 600 / 700 / 800.
- Titres : Poppins bold/extrabold, couleur teal ou navy. Corps : Poppins 400, `line-height 1.65`.

## Logo
Lettrage **« 7utoria »** (teal + accent jaune sur le « T ») avec baseline **« Explorez,
Apprenez, Partagez »** intégrée. Fichier : `public/logo.png` (détouré). Ne pas ajouter le slogan
en texte à côté (il est déjà dans le logo).

## Ton éditorial
Direct · concret · chaleureux · sans jargon · phrases courtes. Tutoie le lecteur. Promesse
constante : **tu lis, tu comprends, tu appliques.**

## Signatures UI (ce qui rend le site reconnaissable)
- **Barre teal** en haut (date/heure en direct + rotateur de titres).
- **Barre de navigation jaune** collante.
- **Ticker « ⚡ ACTU »** défilant.
- **Mise en page magazine** (contenu + sidebar : recherche, récents, rubriques, newsletter teal).
- **Slider** d'articles à la une (Ken Burns + points).
- **Jeu d'icônes maison** (trait fin, arrondi — jamais d'emojis génériques comme icônes).
- Bloc **newsletter teal** avec cloche.
